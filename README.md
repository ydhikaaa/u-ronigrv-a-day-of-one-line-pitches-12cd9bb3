My entry for the make.fun bounty [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

`main.py` writes one sentence to `/output/entry.txt`: a pitch that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. The sentence is the whole entry — the program is deterministic, stdlib-only, and writes the same bytes on every run.
